# План оптимизации CPU бота (vbots2)

## Контекст
Анализ горячих точек (timer.lua / movement.lua / pathfinding.lua / common.lua / commands.lua / dig_build.lua) выявил:

| Место | Стоимость | Статус |
|-------|-----------|--------|
| pathfinding.lua: сортированный массив как очередь A* | O(n²), до 50000 состояний, копирование списка действий на каждое состояние (O(глубина)) | **ГОТОВО** (бинарная куча + parent-указатели, коммит ab2640c) |
| pathfinding.lua: повторные вызовы is_walkable (get_node) на одну и ту же клетку из соседних состояний | ~3-4× лишних get_node на клетку | **ГОТОВО** (локальный кэш на время одного поиска, мир заморожен) |
| timer.lua: bot_pickup_items — get_objects_inside_radius каждый тик | сканирование всех объектов каждые ~0.5с | **ГОТОВО** (троттлинг 1 раз в 5 тиков, коммит ab2640c) |
| movement.lua: to_table/from_table (424 слота инвентаря) на шаг | десятки мкс/шаг — приемлемо при типовом числе ботов | отложено |
| Инвентарь в mod_storage (убрать из меты узла) | большой выигрыш, но рефактор ~8 файлов (формспеки `list[context]`, save/load, команды) | **отложено** — future work |
